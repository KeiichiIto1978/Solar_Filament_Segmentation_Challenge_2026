# Documentation

| Path | Contents |
|---|---|
| [`experiments/`](experiments/) | One record per phase: what was built, what it measured, what was learned, what came next |

Each phase record is written once, when that phase closes, and is not edited
afterwards. It is derived from a detailed working log kept outside this
repository; the numbers here are the ones that were true when the phase ended.
Where a later phase overturned an earlier conclusion, the later record says so
rather than the earlier one being rewritten.
